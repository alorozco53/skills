## Poster workflow

[`new-poster/`](new-poster/) integrates the separately maintained, commit-pinned
[`aumona/poster-harness`](https://github.com/aumona/poster-harness) LaTeX poster
starter. It does not vendor the upstream template or modify the existing
Reveal.js slide-authoring/deployment skills. Read its [skill instructions](new-poster/SKILL.md)
and [setup/testing guide](new-poster/README.md).
